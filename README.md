# POCKET BETTER X

แอปจำลองเครื่องเล่นเกมพกพาสำหรับไฟล์ `.gba` แบบ **ออฟไลน์** (PWA)
ออกแบบมาสำหรับ **iPhone 6 (iOS 12.5.8, Safari 12.1)** เล่นในแนวนอนเป็นหลัก และใช้บนคอม (Chrome/Safari) ได้ด้วย

> แอปนี้ **ไม่มีเกมและไม่มี BIOS ของผู้ผลิตเครื่องต้นฉบับ** ใช้เฉพาะเกมที่คุณดัมพ์จากตลับของตัวเอง หรือเกม Homebrew
> ดีไซน์ตัวเครื่องเป็นแบบออริจินัล ไม่ได้เป็นผลิตภัณฑ์หรือได้รับการรับรองจากผู้ผลิตเครื่องเกมรายใด

---

## ติดตั้งบน iPhone
1. เปิดลิงก์ของแอปใน **Safari** (ต้องเป็น Safari เท่านั้น)
2. แตะปุ่ม **แชร์** › **เพิ่มไปยังหน้าจอโฮม**
3. เปิดแอปจากไอคอนบนหน้าจอโฮม 1 ครั้งขณะต่อเน็ต เพื่อให้แอปเก็บไฟล์ไว้ใช้ออฟไลน์
4. หลังจากนั้นเปิดได้แม้ไม่มีเน็ต

## วิธีใช้
- **＋ เพิ่มเกม** แล้วเลือกไฟล์ `.gba` จากแอปไฟล์ (เลือกได้หลายไฟล์พร้อมกัน)
- แตะการ์ดเกมเพื่อเล่น · ปุ่ม **⋯** บนการ์ด: เล่น / นำเข้า .sav / สำรองเป็นข้อความ / เปลี่ยนชื่อ / ลบ
- **☰ เมนู** ระหว่างเล่น (เกมจะหยุดระหว่างเปิดเมนู): บันทึก/โหลดสถานะ, ความเร็ว x2/x3, เสียง, แสดงความเร็ว %, สเกลจำนวนเต็ม, โหมดประหยัด, ย้อนเวลา, ภาพหน้าจอ, สำรองเซฟ, นำเข้า .sav, รีเซ็ต, ออกจากเกม
- **▶▶** เร่งความเร็ว (ปิดเสียงขณะเร่ง) · **⏪** กดค้างเพื่อย้อนเวลา (ต้องเปิดในเมนูก่อน)
- กด **A+B พร้อมกัน** ได้โดยแตะจุดตรงกลางระหว่างปุ่ม · แตะหลายนิ้วพร้อมกันได้

## BIOS
- ค่าเริ่มต้นใช้ **Cult-of-GBA BIOS** ซึ่งเป็น BIOS ทดแทนแบบโอเพนซอร์ส (MIT) จึงไม่ต้องมีไฟล์ BIOS ต้นฉบับ
- ถ้าเกมไหนไม่ทำงานกับ BIOS ทดแทน ให้ใช้ BIOS ที่ดัมพ์จากเครื่องของคุณเอง: **⚙ › ใช้ BIOS ของฉัน (16KB)** (ไฟล์ต้องมีขนาด 16384 ไบต์พอดี) และสลับกลับได้ที่ **⚙ › ใช้ BIOS เริ่มต้น**

## เซฟเกม
- **เซฟในตลับ** (เซฟจากในเกม) บันทึกลงเครื่องอัตโนมัติทุก 30 วินาที, ตอนเปิดเมนู, ตอนออกจากเกม และตอนสลับไปแอปอื่น
- **สำรองเป็นข้อความ:** iOS 12 บันทึกไฟล์จากหน้าเว็บลงแอปไฟล์ไม่ได้ จึงสำรองเป็นข้อความ (JSON + base64) ให้กด **คัดลอก** แล้วไปวางเก็บในโน้ต/อีเมล เมื่อต้องการกู้คืนให้ไปที่ **⚙ › กู้คืนจากข้อความ**
- **นำเข้า .sav** จากอีมูเลเตอร์อื่นได้ (ขนาดไม่เกิน 256KB)
- ข้อมูลทั้งหมดเก็บใน IndexedDB ของ Safari ถ้าลบข้อมูลเว็บไซต์หรือลบแอปออกจากหน้าจอโฮม เซฟจะหายด้วย **ควรสำรองเป็นข้อความไว้เสมอ**

## Save State (ฟีเจอร์ทดลอง)
- มี 4 ช่อง + ช่องอัตโนมัติ (บันทึกตอนออกจากเกมและตอนสลับแอป) แต่ละช่องประมาณ 700KB
- ทำงานโดยบันทึกสถานะทั้งหมดของแกนจำลอง (CPU, หน่วยความจำ, กราฟิก, เสียง, ชิปเซฟ) ทดสอบแล้วว่าโหลดกลับได้ตรงทุกไบต์กับ ROM ทดสอบ แต่ **ยังไม่ได้ทดสอบกับเกมจริงทุกเกม** ถ้าเกมผิดปกติหลังโหลดสถานะ ให้ใช้เซฟในเกมแทน
- การโหลดสถานะจะย้อนเซฟในตลับกลับไปเป็นค่า ณ ตอนบันทึกสถานะด้วย
- สถานะผูกกับแกนจำลองเวอร์ชันนี้ ถ้าอัปเดตแกนในอนาคต สถานะเก่าอาจโหลดไม่ได้ (แอปจะแจ้ง ไม่ทำให้เกมพัง)
- **ย้อนเวลา** (⏪) เก็บสถานะทุก 1 วินาที ย้อนได้สูงสุด 20 วินาที ปิดไว้เป็นค่าเริ่มต้นเพราะใช้แรงเครื่องเพิ่ม

## ข้อจำกัดบน iPhone 6 / iOS 12
- **ความเร็ว:** เกม .gba ต้องใช้แรงเครื่องมาก ยังไม่ได้วัดบน iPhone 6 จริง ดูตัวเลข % ที่มุมจอ (สีเหลือง = ช้ากว่า 95%) ถ้าช้า ให้เปิด **โหมดประหยัด** (วาดภาพเฟรมเว้นเฟรม) และปิด **ย้อนเวลา**
- แกนจำลองทำงานบน main thread เท่านั้น เพราะ iOS 12 ไม่มี SharedArrayBuffer/Atomics
- **เสียง** จะเริ่มหลังแตะหน้าจอครั้งแรก (ข้อบังคับของ iOS) และปิดอัตโนมัติขณะเร่งความเร็ว
- **ภาพหน้าจอ:** แอปจะแสดงภาพให้ **กดค้าง › บันทึกภาพ** ลงแอปรูปภาพ
- ไม่รองรับไฟล์ `.zip` ให้แตกไฟล์ก่อนเพิ่มเกม
- แกนจำลองยังไม่แม่นยำ 100% (ROM ทดสอบ arm ตกข้อ 223 และ thumb ตกข้อ 227) บางเกมอาจมีภาพหรือเสียงเพี้ยน
- `core/CPU/THUMB.js` ถูกแก้จากต้นฉบับ IodineGBA: คำสั่ง THUMB แบบ hi-register (ADD/CMP/MOV) ที่ใช้ register ต่ำทั้งคู่ เช่น `mov r3, r0` (0x4603) เดิมถูกมองเป็นคำสั่งผิดจนเกมค้าง ตอนนี้ทำงานเหมือนเครื่องจริง (พบในเกมแปลไทยที่คอมไพล์ด้วยคอมไพเลอร์รุ่นใหม่)

## สำหรับนักพัฒนา
```bash
python3 -m http.server 8080
```
แล้วเปิด `http://localhost:8080/` · ไฟล์ `test.html` ใช้ทดสอบแกนกับ ROM ใน `vendor/test-roms/` (โฟลเดอร์ ROM ทดสอบไม่ได้อยู่ใน repo)

ทุกครั้งที่ deploy ให้เพิ่ม `CACHE_VERSION` ใน `sw.js` และ `VERSION` ใน `js/app.js` ให้ตรงกัน

```
index.html  manifest.webmanifest  sw.js
css/style.css
js/app.js   UI คลังเกม เมนู การควบคุม เซฟ
js/emu.js   ตัวห่อ IodineGBA (เริ่ม/หยุด ปุ่ม ความเร็ว เซฟ Save State frameskip)
js/db.js    IndexedDB
core/       แกน IodineGBA + glue (กราฟิก/เสียง)
bios/       Cult-of-GBA BIOS
```
